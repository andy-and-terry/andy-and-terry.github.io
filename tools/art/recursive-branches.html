Recursive Branches

A branching structure grows from a single trunk, splitting recursively with randomized angle and length. Runs entirely in your browser.

Seed

Same seed and parameters always reproduce the same artwork.

Parameters

Base angle between a branch and its parent.
Random wobble added to every branch angle.
How much shorter each generation of branch is.
Probability a node grows a third, asymmetric branch.

Export

Runs locally via p5.js. No files leave your device.
