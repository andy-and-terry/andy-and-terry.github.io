PDF Toolkit

8 browser-based PDF tools built on pdf-lib and pdf.js. Everything runs locally in your tab — no uploads, no accounts, no server. Pick a tool to get started.

🔗
Merge
Combine multiple PDFs, reorder before merging.
 ✂️
Split
Split by page ranges or extract individual pages.
 🗜️
Compress
Reduce file size by downsampling embedded images.
 🖼️
Image → PDF
Combine images into a PDF, reorder pages first.
 📸
PDF → Image
Export pages as PNG or JPG at your chosen resolution.
 🔄
Rotate / Reorder
Rotate and drag-to-reorder pages with thumbnails.
 🔒
Protect
Add or remove password protection.
 📝
Extract Text
Pull plain text out of a PDF.
Runs locally via pdf-lib and pdf.js. No files leave your device.
